# Кафе 288 — бесплатный таймер

Этот репозиторий содержит только расписание для уже существующего приложения «288 · Заказы». Исходники приложения, заказы, Gmail/OAuth-токены и пароли сюда не передаются.

Стандартный runner GitHub Actions в публичном репозитории бесплатен. У задания нет checkout, сторонних actions, кешей или артефактов. В приватном репозитории задание пропускается до выделения runner. Платёжный аккаунт и карта не нужны.

Таймер примерно раз в 5 минут обращается к существующему серверу по HTTPS. GitHub выдаёт короткоживущий OIDC-токен; сервер проверяет подпись, аудиторию, постоянные ID владельца и репозитория, публичную видимость, ветку main и точный workflow. Gmail-токены остаются зашифрованными на сервере приложения.

Ограничения: GitHub может задержать или пропустить запуск при нагрузке. В публичном репозитории расписание автоматически отключается после 60 дней без активности; его нужно снова включить на вкладке Actions. Ни постоянный браузер, ни телефон для обычных запусков не нужны. Бесплатный сервис не предоставляет гарантированное время доставки.

Расписание продлевает Gmail Watch, восстанавливает пропущенную историю Gmail и отправляет Web Push только для новых писем о заказах. Оно не подтверждает, не отменяет и не изменяет заказы Delivery Guru. Первоначальные старые письма не вызывают массовых уведомлений.
